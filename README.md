# 画面コーチ

Windows常駐の画面記録ツール。ゲームプレイや勉強の様子を録画・定間隔スクリーンショットで記録し、後から自分で(またはAIに見せて)振り返るための道具。

## 紹介サイト

https://tanakatakeshi811-spec.github.io/gamen-coach/

## 機能

- **F9**: 画面全体の録画を開始/停止(mp4で保存)
- **F10**: 一定間隔(既定30秒、変更可)でのスクリーンショット自動保存を開始/停止
- 録画とスクショは独立して動作、同時使用も可能
- セッションごとにフォルダを分けて自動整理保存
- 録画・スクショ・設定はすべてローカル保存。外部サーバーやAIへの自動送信は一切なし

## 使い方

1. このリポジトリをダウンロード(Code → Download ZIP、またはgit clone)して展開
2. Pythonが入っていなければ [python.org](https://www.python.org/downloads/) からインストール(「Add python.exe to PATH」に必ずチェック)
3. `起動.bat` をダブルクリック(初回は必要なライブラリを自動インストール)
4. ウィンドウが開いたらF9・F10で操作開始

必要環境: Windows 10/11、Python 3.10以降
